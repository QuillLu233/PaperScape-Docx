一、启动
--------
1. 解压到普通可写目录。
2. 双击 PaperScape.exe。
3. 不需要安装、管理员权限或后台服务。
4. 需要系统已有 Microsoft Edge WebView2 Runtime（Windows 10/11 通常自带）。

二、Phase 4 Windows 音乐控制台
----------------------------
- 使用 Windows GSMTC 读取外部播放器的媒体会话。
- 状态栏右侧显示紧凑音符入口；无会话时也可打开检测面板。
- 当前歌曲名称在检测到会话后显示。
- 专注模式右下角保留音符入口，默认 60% 透明度。
- 点击音符向上展开完整音乐控制面板。
- 面板显示封面、歌曲、歌手、专辑、来源、播放进度。
- 支持播放/暂停、上一首、下一首、进度调整。
- 支持自动跟随系统当前会话，或固定指定播放器。
- 设置中可折叠“音乐控制台”分组，可关闭监听。

- 媒体命令在后台线程执行；轮询有防重入保护，避免播放器会话异常时阻塞编辑器。\n\n三、当前限制
------------
- 使用前端轮询刷新媒体状态，尚未接入 GSMTC 事件推送。
- 播放器未提供的字段和控制会显示为空或禁用。
- 实际音乐播放由外部播放器负责。
- 当前隔离测试只验证了 Microsoft Edge 音频会话；QQ 音乐、网易云音乐、Spotify、Chrome、Windows 本地播放器未安装或未提供会话。

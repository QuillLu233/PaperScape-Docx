一、启动
--------
1. 将整个文件夹解压到你有写入权限的普通目录（例如 Documents\PaperScapePortable）。
2. 双击 PaperScape.exe。无需安装、无需管理员权限、无需命令行或开发服务器。
3. 本版本不包含 NSIS/MSI 安装程序，也不修改 Windows 注册表或系统环境变量。

系统要求
--------
- Windows 10/11 x64。
- 需要系统已安装 Microsoft Edge WebView2 Runtime。Windows 11 通常已自带；如启动失败，请从 Microsoft 官网安装 WebView2 Runtime。
- 本便携包不包含 WebView2 Runtime，也不包含 Electron 或其他大型运行时。

二、文件与数据位置
------------------
- 文稿由你选择保存位置；默认建议 Documents\PaperScape。
- 应用配置、最近项目、字体和缓存位于当前 Windows 用户的 AppData 目录，不写入便携包目录。
- 软件不会强制把正文保存到隐藏的 AppData 目录。
- 软件不会在升级或退出时删除你的文稿。
- “设置默认文稿目录”“打开文件夹”“在资源管理器中显示”可查看真实路径。
- 直接保存 DOCX 前会创建备份；存在格式风险的文件应先另存为，并保留原文件。

三、V1 升级注意事项
--------------------
- V1.0 项目仍可打开；章节内容和项目外观保留。
- 建议升级前备份重要项目：直接复制整个 .paperscape 项目文件夹。
- 本次没有迁移或删除任何 V1 用户项目。
- V1.0 安装包仍在原发布目录，不会被本绿色版覆盖。

四、已包含的 V1.1 功能
----------------------
- 帮助 → 关于纸境：显示软件图标、当前版本、创作者与版权信息；普通写作、专注/全屏和导出文件均不添加作者水印。
- 滚动流畅度优化：普通滚轮不再被非被动脚本拦截，长文滚动更顺；文稿信息栏移除实时毛玻璃背景，减少滚动重绘。
- 最大化改为“填充当前显示器工作区”的无边框窗口，保留任务栏并绕过 Windows 原生最大化合成路径；最大化/还原后立即激活窗口，视口和滚动区同步适配。
- 在文件树切换 DOCX 时保留当前编辑区和工作区，等新文档读取完成后再替换，避免整页闪白或像重新加载一帧。
- 工具栏“首行缩进”会写入 DOCX 的 w:ind firstLine，重新打开时恢复到编辑器；标准保存和导出都保留。
- 中文双引号输入会根据上下文纠正明显的反向输入；校对不再把跨段对话开头的引号误报为未闭合。
- 舒适写作：正文底部保留约 25% 可视高度留白，光标接近底部自动跟随；向上翻阅时暂停，重新输入后恢复；适配最大化、专注全屏和缩放。
- 编辑器内部支持按住鼠标拖动选中文字：同段/跨段移动、显示插入位置、保留格式、Ctrl 拖动复制、撤销重做和拖到边缘自动滚动；外部文件/文件夹拖入仍使用 Tauri 原生通道。
- 文件模式下“章节”菜单入口明确禁用并提示仅适用于 V1 项目；所有禁用菜单项增加明显灰化，避免看起来可点但没有反应。
- “新建项目”直接从菜单/欢迎页打开创建表单；新建文稿在自动保存模式下首次输入后会自动生成 DOCX，不再停留在无路径草稿。
- 文件模式下“视图 → 沉浸式/纸张式”不再灰掉，可直接切换并保存到文件模式外观设置。
- 真实文件夹文件树、直接打开和保存 DOCX、自动备份与外部修改检测。
- 文稿编辑停止约 1.5 秒后自动保存回原 DOCX；只读、格式风险或外部修改时不自动覆盖，保留恢复草稿。
- 设置 → 保存方式可切换“自动保存/手动保存”；自动模式已保存时隐藏保存按钮，手动模式保留保存按钮。
- 文件模式（文件夹/DOCX）可单独设置背景、纸张和写作模式；设置保存在本机，不写入 DOCX。
- 启动时恢复上次项目/文件夹，精简欢迎页。
- 界面字号、独立界面缩放和文稿缩放。
- 顶部项目名居中与真实路径查看。
- F11 原生全屏（全屏期间临时置顶以覆盖 Windows 11 任务栏，退出即取消置顶）、专注写作模式（半透明纸张、背景调节）。
- 从普通窗口进入专注模式会自动全屏，退出专注恢复原窗口；文稿信息栏可收起，仅保留顶部展开箭头；自动保存模式下空闲约 6 秒自动收起（可在设置关闭）。
- 中文输入法组合状态 Esc 保护。
- Windows 系统字体、导入 TTF/OTF、界面字体/正文字体分离。
- 离线中文规则校对（可关闭；只检查当前段落）。

五、已知限制
------------
- 普通文档空闲内存实测约 395 MB Working Set（含 WebView2 子进程）；V1 项目空闲约 379 MB。未达到 150 MB 挑战目标；空闲 CPU 实测约 0.01%–0.04%。
- 冷启动在系统和 WebView2 缓存已热的情况下约 0.05–0.26 秒；严格清空系统缓存的冷启动未测。
- 中文输入法候选框已在 Windows 150% 缩放、普通/专注/全屏模式下人工验证；100%/125% 系统缩放未验证。
- 字体导入文件选择、100%/125% DPI、极端窄窗口、保存失败和外部修改的真实 GUI 演练仍需按开发记录人工验收。
- 中文校对是规则检查，不具有完整语义理解；只标当前段落，不会自动替换正文。

六、隐私与离线
--------------
- 校对和 DOCX 转换全部本地运行，无在线 API、无模型下载、无后台服务、无遥测。
- 本包不包含 API Key、Token、密码、私人文稿、测试文稿或源代码。

七、卸载
--------
- 直接删除便携文件夹即可；如需清理配置，可删除当前用户的
  %APPDATA%\com.paperscape.desktop 和 %LOCALAPPDATA%\com.paperscape.desktop。
- 删除配置不会删除你的文稿。
